# Unofficial Stabfish2 Client

> ⚠️ This is an unofficial client for Stabfish2 and is not affiliated with or endorsed by the original developers.

## About

Unofficial Stabfish2 desktop client, created to provide a more convenient way to access the game as a standalone application.

This application is packaged from the Stabfish2 website using **Pake**.

## Download

You can download the latest Windows installer from the [Releases](../../releases) page.

The installer is provided as an `.msi` file.

## Built With

This application was packaged using **Pake**.

Pake is an open-source tool for packaging webpages into desktop applications.

Learn more about Pake:

https://github.com/tw93/Pake
